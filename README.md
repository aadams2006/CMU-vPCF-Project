# Deep Embedded Clustering for VPCF Analysis
framework for using deep embedded clustering to cluster vector pair correlation function (VPCFs) from STEM data

## Project Structure
- `Experimentally-Obtained vPCF Testing/`: Current working directory with all data, testing, results, etc
- `Usused Data/`: Prior datasets and results that are no longer relevant
- `Usused Algorithms/`: Prior experimental scripts/functions no longer in use
- `requirements.txt`: required Python libraries
