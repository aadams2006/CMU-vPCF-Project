# Original synthetic H5 map-back

Assignments join to original H5 frame indices and atomic_positions through the existing VPCFToImageMapper, then plot on the original DM3 without rescaling. Gray circles mark all source coordinates; colored circles mark tested frames. The original smoke test uses the first 12 of 380 frames, one pretraining epoch and two refinement iterations. This is a pipeline smoke test, not a full boundary study. Cluster IDs have no established bulk/interface semantics.
