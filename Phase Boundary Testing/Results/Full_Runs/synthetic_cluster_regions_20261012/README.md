# Original-image cluster regions

K=3 and K=6 DEC/IDEC saved models are applied to all 380 original H5 samples. Models were trained on 12 samples; remaining 368 assignments are inference. No retraining, clustering on pixel coordinates, smoothing or semantic relabeling occurs. Min-max normalization uses the original 12 training frames. cluster_regions.png colors nearest-sample regions without text inside the image. All clusters appear in the legend. all_sample_cluster_labels.png colors every atomic sample like the reference. The inferred boundaries are display interpolation, not physical ground truth. IDs are model/run-specific; the same ID across runs need not mean the same phase. summary.csv records occupied counts and any disagreement between saved fit labels and reloaded final-weight inference.
